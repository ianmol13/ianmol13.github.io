// story

My journey into cybersecurity didn't start with a course or a degree — it started with curiosity. I wanted to know how systems break before I could understand how to build them. That mindset has shaped everything I do.

I began as a complete beginner, learning through free resources and building small tools just to see how things worked. Over time that evolved into serious hardware hacking, RF exploitation, and offensive security research. Every project I've built — from a Subdomain Enumeration Engine to a cryptographic Password Vault — exists because I wanted to understand the attack surface, not just defend it.

At IEEE HIT, leading 5+ technical events taught me that great security work isn't just technical — it's about communication, coordination, and making complex ideas accessible. I bring the same clarity to my code.

Outside of hacking, I practice CTFs on TryHackMe and HackTheBox, analyze malware samples, and document what I learn. I believe the best security engineers are perpetual students — always one step behind the attacker, always trying to close the gap.

Currently grinding the eJPT → CEH → OSCP certification track while building hardware security tools and contributing to open-source security projects.

// Projects

01

Secure Password Vault (Java)

A fully encrypted Java password manager built with AES and PBKDF2 for maximum security.

I have always been fascinated by how encryption protects our most sensitive data, so I built a secure password vault completely from scratch using Java's standard libraries. It uses AES-128-GCM encryption and PBKDF2 for key derivation, ensuring strong data security without external dependencies.

I also created both CLI and GUI interfaces, implemented rate limiting and memory safety, and added an automatic backup system to make it production-grade.
This project taught me how cryptography and software engineering blend together to create truly secure applications.

Subdomain Enumeration Tool

A high-speed Python tool that uncovers hidden subdomains using OSINT APIs and multithreading.

This project began as my curiosity about how hackers uncover hidden parts of a website. I developed a Python-based Subdomain Enumeration Tool that integrates crt.sh and Sublist3r APIs to scan over 500 subdomains per hour.

To make it efficient, I implemented multi-threading, boosting scan speed by 40%, and added an export-to-CSV feature for better usability.

Through this project, I deepened my understanding of OSINT, API integration, and automation in reconnaissance workflows.
